API de Raldamain

Los datos del juego en JSON, para cualquier aplicación

Dirección base: https://raldamain.com/api/v1

Solo lectura (GET), sin clave y abierta a cualquier web o aplicación (CORS). Sirve lo mismo que publica la web, leído al momento de los archivos del juego: un cambio guardado en los editores aparece aquí en cuanto la web se actualiza. Las criaturas y objetos sin publicar no salen (dan 404).

Empieza por /api/v1: lista todo lo que hay y cuántos de cada uno.

Colecciones

ListaUnoQué es
/ranks/ranks/{id}Rangos: niveles, habilidades, fundamentos.
/equipment/equipment/{slot}/{id}El equipo de las fichas (armas, armaduras, cabeza, bolsa), cada uno con la habilidad que da en ability. /equipment/weapons da solo las armas.
/items/items/{id}El catálogo de objetos de la web (objetos mágicos y demás).
/creatures/creatures/{id}Criaturas del Bestiario, con su bloque de estadísticas.
/statblocks/statblocks/{id}Fichas de personaje (formato del Creador): características, rangos, talentos, equipo.
/status-effects/status-effects/{id}Efectos de estado y sus penalizadores por nivel.
/builder/builder/{nombre}Las tablas de creación de personajes tal como están guardadas: talents, races, archetypes, arcane-specs, divine-patrons, equipment, equipment-abilities.

Una lista es un array con el resumen de cada uno, más url (su dirección en la API) e image_url cuando tiene imagen. Uno es el documento completo, exactamente como está guardado. Las direcciones también valen terminadas en .json.

Filtrar las listas

ParámetroQué hace
q=duelistaBusca en el nombre y la descripción (sin tildes ni mayúsculas).
<campo>=<valor>Filtra por un campo de la lista: category=Marcial, type=Bestia, draft=false, rarity=Rara… Sin tildes ni mayúsculas; en un campo que es una lista, que lo contenga.
min_level=5&max_level=8Nivel mínimo y máximo.
fields=id,nameSolo esos campos.
limit=20&offset=40Paginación. El total va en la cabecera X-Total-Count.
full=1Cada uno con su documento completo en document (una sola petición en vez de una por elemento).

Ejemplos

JavaScript (en el navegador o en Node)

const API = 'https://raldamain.com/api/v1';

// los rangos marciales
const marciales = await fetch(`${API}/ranks?category=marcial`).then(r => r.json());

// uno entero
const coloso = await fetch(`${API}/ranks/estilo_coloso`).then(r => r.json());

// criaturas de nivel 5 a 8, con su bloque completo
const criaturas = await fetch(`${API}/creatures?min_level=5&max_level=8&full=1`).then(r => r.json());
criaturas.forEach(c => console.log(c.name, c.document.hits));

Python

import json, urllib.request
API = "https://raldamain.com/api/v1"
armas = json.load(urllib.request.urlopen(f"{API}/equipment/weapons"))
for a in armas:
    print(a["name"], a["ability"] and a["ability"].get("damage"))

Terminal

curl https://raldamain.com/api/v1/statblocks/arthor

Detalles

  • Errores: un JSON {"error": "…"} con su código (404 si no existe o no está publicado, 405 si no es GET).
  • Las respuestas se pueden guardar 60 segundos (Cache-Control); después, pregunta de nuevo.
  • La versión va en la dirección: si la forma de las respuestas cambia, será en /api/v2.
